Findings

R-LOG-01

Header renders the Payload CMS logo, not the RDI mark.

The <Logo> component loads https://raw.githubusercontent.com/payloadcms/payload/.../payload-logo-light.svg with alt="Payload Logo". Visible at the top of every page.

src/components/Logo/Logo.tsx · line 25–27
Fix · F1

Replace the <img> with an inline SVG import or a next/image reference to public/brand/rdi-logo.svg (mirrored from brand/assets/rdi-logo.svg). Export both <Logo> (full lockup) and <LogoMark> (mark-only).

R-COL-01

Eyebrow text is red across the page.

Every section's eyebrow uses text-rdi-accent (red text). Violates the brand's most-broken rule. Visible on the hero, methodology highlights, use-cases preview, and quote CTA.

src/components/rdi/InstitutionalPage.tsx · <Eyebrow> component, line 6
Fix · F5

Change text-rdi-accent → text-rdi-ink. Drop the responsive sizing for fixed text-[11px]. The eyebrow is plain uppercase Ink — the red lives under the H2 via <SectionTitle> (F6), not next to the eyebrow.

R-TYP-01

Geist Sans, not Inter.

The portal ships geist@1.3.0 from package.json and references --font-geist-sans in globals.css. The brand book declares Inter.

package.json + src/app/(frontend)/layout.tsx
Fix · F3

Remove geist from package.json. Load Inter + JetBrains Mono via next/font/google (or self-hosted under public/fonts/) in layout.tsx. Variable names --font-sans/--font-mono stay — only the source changes.

R-RED-01 + R-RED-05

Section H2s render without the red rule.

Multiple H2s on the home page render bare. The page's signature pattern — H2 with 64×3px red rule beneath — is missing across sections.

app/(frontend)/page.tsx
Fix · F6

Introduce a <SectionTitle> component in src/components/rdi/InstitutionalPage.tsx that renders H2 + the 64×3px red span beneath. Refactor the home-page sections to use it. Watch out for the restraint rule — one rule per section, not per heading.
