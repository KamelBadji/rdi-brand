Forbidden patterns

text-rdi-accent, text-red-*, hardcoded bg-[#...], inline style={'{'}{'{'} color: '...red...' {'}'}{'}'}. The no-red-text rule is the brand's most-broken convention. An ESLint rule rejecting these is on the v1.1 roadmap; until it lands, code review enforces.

Button

Primary on Signature Red fill only. Never red text. Hover darkens fill to Red Strong; ghost variant uses the red line as bottom border on hover.

Variants

tsx

Rules: Primary fills only on Signature Red. Hover darkens the fill, never changes text to red. Ghost hover reveals a 2px red bottom border (the red line). Disabled = 45% opacity + cursor-not-allowed.

Audit findings

Six issues the portal carries against the v1.0 system. Walk this list before declaring brand alignment done.

Logo component renders the Payload CMS placeholder

Critical

Every page in the portal ships with the wrong logo until this lands. The image is loaded from a public GitHub URL with alt="Payload Logo".

src/components/Logo/Logo.tsx
Fix · Replace the <img> src with a local SVG import from brand/assets/rdi-logo.svg. Export both <Logo> (full lockup) and <LogoMark> (mark-only).

Favicon is the wrong file

Critical

public/favicon.svg is a stock chevron from the Payload template, not the RDI mark.

public/favicon.svg
Fix · Replace with brand/assets/rdi-favicon.svg. Regenerate favicon.ico from the new SVG.

Eyebrow uses red text

High

The existing <Eyebrow> component is set to text-rdi-accent — red text. Violates the no-red-text rule (global brand policy, owned by Kamel).

src/components/rdi/InstitutionalPage.tsx
Fix · Change to text-rdi-ink. Drop responsive sizing for fixed text-[11px].

Section H2s have no red rule

High

Most pages render an eyebrow + heading without the 64×3px red line beneath. The brand's primary signature pattern is missing across the portal.

Multiple pages in src/app/(frontend)/
Fix · Introduce a <SectionTitle> component and refactor existing pages to use it.

Font mismatch: Geist Sans, not Inter

High

The portal ships geist@1.3.0; the brand book declares Inter. The mismatch is visible in every page's body type and breaks parity between Figma and code.

package.json + src/app/(frontend)/layout.tsx
Fix · Remove geist from package.json. Load Inter + JetBrains_Mono via next/font/google in layout.tsx.

Error variable may equal Signature Red

Medium

The current --error in globals.css may still resolve to oklch(75% 0.15 25deg) — too close to Signature Red. The v1.0 system holds Error at #9A1014.

src/app/(frontend)/globals.css
Fix · Update --error to oklch(40% 0.15 27deg) (#9A1014).

Page review checklist

Run this pass against any page or component in the portal before approving it as brand-aligned. Print it, paste it into PRs, or load it into a review session.

  1. No red text. Search the page for any element with text-rdi-accent, text-red-*, or inline color: ...red.... If any exists, fix before merging.
  2. Eyebrow + SectionTitle pattern. Each section opens with a plain Ink uppercase eyebrow and a main title (H2), with a 64×3px red rule beneath the title.
  3. Logo is the real RDI mark. Confirm the <Logo> component is rendering the local SVG, not the Payload placeholder.
  4. Favicon is the RDI mark. Open browser dev tools and verify.
  5. Tokens, not hex codes. No bg-[#C3161C], no inline color styles.
  6. Numbers in Mono. Dates, IDs, coordinates, counts, percentages.
  7. Buttons. Primary on Signature Red fill; ghost hover reveals a 2px red bottom border; never red text.
  8. Cards. Hover reveals a 3px red left border.
  9. Forms. Focus state shows a 2px Signature Red outline. Error state has red border + Ink text.
  10. Alerts. Left red border + Red Soft background + Ink-color message text.
  11. Links. Underline thickens to red on hover; text stays Ink.
  12. Active nav. Vertical tabs show a 2px red left rail on hover and active.
  13. Dark mode. Toggle data-theme='dark' and recheck — no red text, contrast still holds.
  14. Focus rings. Tab through every interactive element. Focus must be visible.
  15. Keyboard. Tab order follows reading order. Enter / Space operates every clickable.
  16. Decorative SVG. Red lines, icon wedges, dividers carry aria-hidden="true".
  17. Reduced motion. prefers-reduced-motion: reduce respected on any transition longer than 200ms.

Roadmap

Four phases from current state to a fully aligned design system. Each phase ships independently and validates the next.

v1.1

Stabilize tokens

Apply v1.0 palette to globals.css. Fix Logo + favicon. Migrate Geist → Inter. Introduce SectionTitle. Remove red text from Eyebrow. Add ESLint rule.

v1.2

Component coverage

Document and standardize all components in src/components/rdi/. Add a /design-system route exposing every component live. Playwright visual regression.

v1.3

Bespoke iconography

Replace Lucide on marketing surfaces with a 24-icon RDI set. Keep Lucide for utility icons (chevrons, close, ellipsis).

v2

Brand surface coverage

Slide deck masters, email templates, print master files. All consume the same tokens.
